Radar

Find and identify every device on your Wi-Fi, with a signal finder.

Radar lists the devices on the network you are connected to, works out what each one is (camera, computer, phone, TV, printer, smart-home, router) and shows them on a phone-friendly page. A website cannot scan your network, so Radar is a small Python program you run on a device that is on that Wi-Fi. Nothing is installed and your device list never leaves your network.

Download wifi_scanner.py

iPhone or iPad (everything on the phone)

Install the free app "a-Shell" from the App Store, open it, and paste:
curl -O https://radar.ackerworks.com/wifi_scanner.py
python3 wifi_scanner.py
Tap Allow when iOS asks to find devices on your local network. The device list prints in a-Shell after about 40 seconds. Next time, just run the second line.

Android phone (everything on the phone)

Install Termux and Termux:API from F-Droid, then in Termux:
pkg install -y python termux-api curl
curl -O https://radar.ackerworks.com/wifi_scanner.py
python wifi_scanner.py

Mac or Linux computer

curl -O https://radar.ackerworks.com/wifi_scanner.py
python3 wifi_scanner.py

Windows computer

Needs Python from python.org. In PowerShell:
curl.exe -O https://radar.ackerworks.com/wifi_scanner.py
python wifi_scanner.py

Then

Open the link it prints. Use the "From phone" link to view it on any phone on the same Wi-Fi (this is how to use it with an iPhone).

Good to know

  • Only scan networks you own or are allowed to check.
  • The signal finder measures from the device running Radar, and can only range devices that broadcast their own Wi-Fi radio (routers, extenders, many printers, cameras and TVs).
  • Phones hide hardware addresses from apps, so scans run on a phone identify devices by name and services only. A computer scan also shows the hardware maker.
  • iPhones do not let apps read Wi-Fi signal strength, so the signal finder is not available when Radar runs on an iPhone.
